Tyylitelty esittelysivu

Tyylittele valmis HTML-esittelysivu erillisellä CSS-tiedostolla ilman Flexboxia tai Gridiä.

Uusi aihe: CSS:n perusteetKertaa osat 1–1HTML + ulkoinen CSS
Ensimmäinen osaKaikki harjoituksetOsa 2 →

Tehtävän tavoite

Suunnittele ja toteuta tyylitelty esittelysivu. Uusi CSS-aihe on CSS:n perusteet, mutta lopputuloksessa pitää näkyä myös jokainen aikaisemmissa osissa opittu asia.

Kumulatiivinen periaate: osa 1 sisältää osien 1–1 osaamisen. Valitse ominaisuudet käyttötarkoituksen mukaan ja perustele ratkaisut, joilla on useita mahdollisia toteutustapoja.

Projektin tiedostorakenne

osa1-css-kokonaisharjoitus/
├── index.html
└── css/
    └── styles.css
  • Luo projekti osa1-css-kokonaisharjoitus ja käytä erillistä CSS-tiedostoa.
  • Pidä index.html yksin projektin juuressa. Sijoita kaikki muut HTML-sivut pages-kansioon ja CSS-tiedostot css-kansioon.
  • Toteuta jokainen osaamistaulukon kohta omassa projektissasi. Kirjoita lyhyt kommentti vaikeimman ratkaisun perusteluksi.
  • Kokeile ensin itse. Avaa malliratkaisu vasta testauksen jälkeen.
  • Älä käytä Flexboxia tai Gridiä ennen kuin ne kuuluvat harjoituksen opittuihin asioihin.

Työvaiheet

  1. Tutki annettu HTML ja merkitse, mitkä osat tarvitsevat layoutin, visuaalisen hierarkian tai vuorovaikutustilan.
  2. Luo kansiot ja linkitä css/styles.css oikein sekä juuren etusivulle että pages-kansion sivulle.
  3. Toteuta ensin osien 1–1 kertaus ennen tämän osan uutta tekniikkaa.
  4. Lisää osan 1 ratkaisu ja tarkista selaimen DevToolsilla, mikä sääntö todella voittaa.
  5. Testaa pitkä teksti, kapea näkymä, näppäimistö ja vähintään yksi poikkeustilanne.
  6. Vertaa malliratkaisuun vasta oman toteutuksen jälkeen ja kirjoita, miksi oma ratkaisusi toimii.

Osat 1–1: pakollinen osaaminen

OsaAiheMiten taito näkyy työssä
1CSS:n perusteetLiitä ulkoinen CSS-tiedosto, kirjoita sääntöjä ja käytä elementti-, class- ja id-valitsimia, värejä, yksiköitä, fontteja sekä perusreunoja.

Osa on valmis, kun…

  • Kaikki osien 1–1 vaatimukset löytyvät CSS:stä.
  • CSS linkittyy oikein sekä juuresta että pages-kansiosta.
  • Selectorit osuvat tarkoitettuihin elementteihin ilman tarpeetonta specificityä.
  • Layout ei aiheuta vaakasuuntaista ylivuotoa.
  • Fokus, kontrasti ja tekstin luettavuus toimivat.
  • Olet testannut ja perustellut keskeiset ratkaisut.
